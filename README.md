# SkiTracker
Master Project for SUPSI

## Prima versione

- `backend/`: API Python/FastAPI per il profilo autenticato con Supabase.
- `frontend/`: app iPhone con Expo, React Native e TypeScript.
- Gli esperimenti di computer vision rimangono nella cartella separata `Models_Test`.

Il frontend include registrazione, login, sessione persistente, logout e
modifica del profilo. Video e analisi verranno aggiunti in seguito.

Per avviare l'app su iPhone, segui [frontend/README.md](frontend/README.md).
